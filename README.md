# Compiler Construction - Phase II

## Syntax Analyzer and Symbol Table

This project implements Phase II of the Compiler Construction course project.

Phase II takes the token output generated by the lexical analyzer from Phase I and performs:

- Top-Down Syntax Analysis
- Syntax Error Detection
- Error Recovery
- Symbol Table Generation

## Features

- Top-down parsing
- Syntax analysis of C-style programs
- Support for `int`, `char`, and `void`
- Function and `main` parsing
- Variable declarations
- Array declarations
- Assignments
- Arithmetic expressions
- Conditional statements
- `if / else`
- `while`
- `for`
- `return` statements
- Symbol table generation
- Line-numbered syntax errors
- Error recovery by skipping tokens on the erroneous line
